## 三、核心设计要点

### 1. "连续量 vs 开关量"的视觉区分（贯穿全站）

| | 前三路（灯/声/振） | 第四路（继电器） |
|---|---|---|
| 控件 | 滑杆 + 时长 | **无滑杆**，只有 Switch |
| 开关切换 | — | **无过渡，瞬时** |
| 可视化 | 渐变环 / 声波 / 抖动条 | 两态方块硬切 |
| 预览条 | 平滑 / 脉冲 / 高频抖动 | 硬切 |

用户**不需要读文字**，看形态就知道这四路不是一回事。

### 2. 右侧常驻状态指示器（你的创新点 · v2 重写 · v2.1 去标题）

- 位置：控制台壳层最右，`76px`，`position: sticky`
- 结构：栏头（**仅连接徽标**，v2.1 删除竖排标题）+ 四个状态槽 + 底部心跳
- 每个状态槽固定四段式：**图标容器 → 中文名（常显）→ 电平轨道 → 状态词**
- **继电器不用轨道，用 ON/OFF 两态灯块** —— 形态差异而非颜色差异
- hover 槽位浮出 tooltip（`灯光 · light.main · 亮度/渐变/时长`）
- 与模拟器 / 设备 / 调试页**共用同一状态源**，任一页触发右栏同步
- 填充只动 `height`（图示量化，非布局动画）；继电器 `0ms` 硬切

### 3. 避免"AI 味"的具体做法

| 问题 | 本方案对策 |
|---|---|
| 卡片套卡片、层层阴影 | **卡内分组用 `--bg-sunken` 色块，无阴影无边框**；同层只有一层阴影 |
| 卡片一样大、无主次 | 设备页：`1.25fr : 1fr` 双栏；调试页：`1fr : 360px`；KPI 卡 96px 固定，内容卡自适应 |
| 霓虹/高饱和到处用 | **全站单一强调色**（蓝）+ 每屏蓝色元素 ≤ 3 处；**v2.1 追加：禁止彩色渐变** |
| 每个标题配解释文字 | 标题下**不挂说明句**；线框图里已删除所有解释性副文案 |
| 圆角/阴影/间距无体系 | 全部收敛到 token：圆角 7 档、阴影 7 档、间距 12 档 |
| **脉冲点胶囊标签**（v2.1） | **已删除** `.eyebrow` —— 这是最典型的「AI 味」符号 |
| **背景粒子 + 彩色光带**（v2.1） | **已删除** —— 改为单点冷调柔光 + 4.5% 噪点的静态四层 |
| **渐变文字**（v2.1） | **已删除** —— 改为白色 + 发丝下划线 |

### 4. 动效严格遵守你的准则

| 准则 | 实现 |
|---|---|
| hover 为主 | 所有卡片、按钮、导航项、列表行都有 hover 态 |
| 不做点击缩放 | active 仅变色/回位，**全站无 `scale` 按压** |
| 键盘 focus | 所有可交互元素 `:focus-visible` + `--shadow-focus` 外环 |
| 只动 transform/opacity | 白名单：transform / opacity / filter / 颜色 / box-shadow / clip-path |
| 时长分档 | 90 / 140 / 260 / 360 / 480 / 700ms，与你的准则逐条对齐 |
| reduced-motion | CSS 全局兜底 + JS 层 `matchMedia` 双重判断；首访判定同步执行 |

## 四、原型怎么用

1. 直接双击打开 `prototype/index.html`（深色首页）
   - 刷新页面看三词依次揭示
   - 滚动看导航吸附 + 区块入场
   - 鼠标移动看主视觉轻微视差
   - 点「我是玩家」跳到控制台

2. 打开 `prototype/console.html`（浅色控制台）
   - 左侧图标栏 / 顶部 tab 切换 7 个页面
   - **模拟器页**：点卡片里的「触发」，看卡内可视化 + **右侧预览条同步动效**（这两个用的是同一时间源）
   - **设备页**：继电器开关是**瞬时切换**（对比其他控件有过渡）
   - **文档页 / 调试页**：内容全部是占位符，只展示结构
   - `Ctrl/Cmd + K` 聚焦搜索框
   - 全部元素支持 Tab 键遍历，能看到 focus 环

3. 系统开启「减弱动态效果」后重新打开，所有动效停止，三词直接全显
