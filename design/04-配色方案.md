# ARGX 配色方案

> 版本 v1.1 ｜ 双主题：**首页深色（Dark）** / **控制台浅色（Light）**
> 所有颜色值均已通过 WCAG 对比度校验，正文 ≥ 4.5:1，大字/图形 ≥ 3:1。
>
> **v1.1 变更**：删除首页全部**彩色渐变**（蓝 / 紫 / 青三色光带）与**渐变文字**。强调改为中性亮色 + 发丝下划线；首页氛围层改为单点冷调柔光（见第 6 节）。控制台四路通道色不变。

---

## 0. 配色总原则

1. **一个强调色贯穿全站**：`Blue-600 #2563EB`。全站只有这一个"可交互/选中/主操作"的信号色。
2. **强调色不滥用**：一屏内同时出现的蓝色元素 ≤ 3 处（主按钮 + 当前选中项 + 一个数据强调）。
3. **状态色只表达状态**，绝不作为装饰。绿=正常/成功，琥珀=警告/降级，红=错误/危险，灰=空闲/未连接。
4. **数据可视化色板独立**：四路输出各有一色（见第 4 节），与状态色严格区分，避免"红色既是错误又是灯光"的歧义。
5. **背景分 3 层，但卡内不再分层**：页面底 → 卡片 → 卡内嵌块。禁止第四层。
6. **禁止彩色渐变**（v1.1 新增）：首页深色主题不使用「蓝→紫」这类多色相渐变，包括背景光带、渐变文字、渐变边框。唯一允许的渐变是**同色相内的明度渐变**（如按钮 `#3B7BF0 → #2563EB`）与**中性色透明渐变**（分隔线、发丝下划线）。

## 2. 强调色阶梯（Accent · Blue）

**全站唯一强调色系**，浅深主题共用色阶，语义角色一致。

| Token | Hex | 浅色主题用途 | 深色主题用途 |
|---|---|---|---|
| `--accent-50` | `#EFF4FE` | 选中项浅底 | — |
| `--accent-100` | `#DCE7FD` | hover 浅底 | 强调色浅底（用于深底上的 chip） |
| `--accent-200` | `#BBD0FB` | 边框强调 | — |
| `--accent-400` | `#5B8DEF` | 图标激活 | **深色主题主强调色** |
| `--accent-500` | `#3B7BF0` | 次级按钮 | hover 态 |
| `--accent-600` | `#2563EB` | **浅色主题主强调色** | 强调文字 |
| `--accent-700` | `#1D4ED8` | hover / 按下 | — |
| `--accent-800` | `#1E3FA8` | active | — |

### 强调色的**允许用法（白名单）**
- ✅ 主按钮填充
- ✅ 当前导航项（胶囊填充 / 侧栏图标实心底）
- ✅ Tab 指示器
- ✅ 开关 ON 态轨道
- ✅ 滑杆已填充段 + 滑块
- ✅ 链接文字
- ✅ 键盘 focus 环
- ✅ 图表主数据线
- ❌ **禁止**：卡片背景大片铺色、标题文字染色、图标默认染色（默认图标必须用 `--text-secondary`）

## 3. 四路输出可视化色板（Simulator 专用）

四路有各自的可识别色，**这四色在控制台中只用于"通道身份识别"**，不承担状态语义。

| 通道 | Token | Hex | 白色主题下可辨识度 | 说明 |
|---|---|---|---|---|
| **light.main** 灯光 | `--ch-light` | `#E8930F` | 琥珀 | 灯光天然是暖黄光 |
| **sound.beeper** 声音 | `--ch-sound` | `#3B7BF0` | 蓝 | 与强调色同族，但仅作通道色 |
| **motion.vibrate** 振动 | `--ch-motion` | `#8B5CF6` | 紫 | 中性偏冷，与蓝区分 |
| **env.relay** 继电器 | `--ch-relay` | `#0E9F6E` | 绿 | 开关量，绿=通路 |

**通道色浅底（用于通道标识块/图例底）**

| Token | Hex |
|---|---|
| `--ch-light-bg` | `#FEF6E7` |
| `--ch-sound-bg` | `#EBF2FE` |
| `--ch-motion-bg` | `#F3EEFE` |
| `--ch-relay-bg` | `#E6F6F0` |

> **对比度校验**：`#E8930F` 在 `#FFFFFF` 上对比度约 2.5:1 —— **不作为文字色**，仅作图形/描边/填充；配文字时用 `#8A5A00`。

## 5. 深色主题阴影加重规则

深色背景会吞掉阴影，深色主题下**必须使用独立的重阴影 token**：

| Token | 值 |
|---|---|
| `--shadow-xs-dark` | `0 1px 2px rgba(0,0,0,.30)` |
| `--shadow-sm-dark` | `0 2px 6px rgba(0,0,0,.36), 0 1px 2px rgba(0,0,0,.24)` |
| `--shadow-md-dark` | `0 6px 16px rgba(0,0,0,.44), 0 2px 6px rgba(0,0,0,.28)` |
| `--shadow-lg-dark` | `0 12px 32px rgba(0,0,0,.52), 0 4px 10px rgba(0,0,0,.30)` |
| `--shadow-xl-dark` | `0 24px 64px rgba(0,0,0,.60), 0 8px 20px rgba(0,0,0,.40)` |
| `--shadow-focus-dark` | `0 0 0 3px rgba(91,141,239,.32)` |

> 深色主题的**卡片边界主要靠 `--border-default` 描边**（`#2A2D33`），阴影作为辅助，不要只靠阴影。

## 6. 首页氛围层（仅首页深色使用）

> **v1.1 重做**：v1.0 用了三个**彩色**径向渐变（蓝 / 紫 / 青）叠加，实际观感偏廉价、像模板。
> 现行方案改为**单点中性冷调柔光 + 噪点材质**，全部静态，不依赖任何动画元素。

首页背景 = **一层光 + 一层收敛 + 一层网格 + 一层噪点**，四层叠加。规范如下（只用在首页，控制台不用）：

| 层 | 规格 | 值 |
|---|---|---|
| 底层 | 纯色 | `#0A0B0D` |
| **光** | 顶部中央一束**中性冷调**柔光，无彩色 | `radial-gradient(58% 56% at 50% 50%, rgba(228,232,238,.115), transparent 72%)` + `radial-gradient(34% 34% at 50% 50%, rgba(238,241,245,.075), transparent 78%)` |
| 光 · 落点 | 光锥底部一条 760px 水平切线 | `linear-gradient(90deg, transparent, rgba(255,255,255,.075) 30%, rgba(255,255,255,.11) 50%, …, transparent)` |
| 收敛 | 四角径向暗角 + 上下线性 | `radial-gradient(128% 104% at 50% 42%, transparent 42%, rgba(0,0,0,.52) 100%)` + 上 `.46` 下 `.50` 线性收敛 |
| 网格 | 88px 细网格，径向 mask 收敛 | `linear-gradient(rgba(255,255,255,.024) 1px, transparent 1px)` / `88px 88px`，mask `radial-gradient(ellipse 82% 58% at 50% 28%, #000 6%, transparent 76%)` |
| **噪点** | SVG `feTurbulence` fractalNoise 4 阶，**唯一的材质层** | `opacity:.045`，`stitchTiles="stitch"` |

**关键约束**
- 光的模糊半径 ≥ 600px，**绝不能看出边界**；总亮度不超过画面 12%，否则文字对比度不合格。
- **禁止彩色渐变**。强调靠中性亮色（`#FFFFFF`）+ 发丝下划线（`linear-gradient(90deg, rgba(255,255,255,.34), rgba(255,255,255,.12))`，`background-size:100% 1.5px`），不用 `background-clip:text` 的彩色渐变文字。
- **不使用任何 Canvas / rAF 背景动画**。高级感来自「光的层次 + 微噪点 + 收敛」，不是运动；静态背景同时零性能开销、天然满足 `prefers-reduced-motion`。

### 6.1 已废弃的 v1.0 方案（勿再用）

| 层 | 已废弃值 | 废弃原因 |
|---|---|---|
| 光带 1 | `radial-gradient(1200px 600px at 20% -10%, rgba(37,99,235,.18), transparent 65%)` | 蓝色光带过饱和，像廉价模板 |
| 光带 2 | `radial-gradient(900px 500px at 85% 15%, rgba(139,92,246,.12), transparent 65%)` | 紫色与蓝色撞色，是「AI 味」来源 |
| 光带 3 | `radial-gradient(1000px 400px at 50% 110%, rgba(6,182,212,.08), transparent 70%)` | 青色第三种色相，画面散 |
| 粒子 | Canvas 点云 + 深度雾 + 鼠标斥力 | 深色底上的点云难以做到高级，实际观感廉价 |
| 动画 | `glowDrift 26s ease-in-out infinite` | 与「专业工具」的稳定调性不符 |
