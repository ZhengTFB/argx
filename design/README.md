# ARGX 界面设计真源（design/）

**这个目录是整个项目界面视觉的唯一权威。** 任何与界面长相有关的问题，答案都在这里，
不在 `console/src/` 的旧代码里，也不在 `docs/` 的旧任务书中。

---

## 一、谁是权威

改界面时按这个顺序找答案，排在前面的说了算：

| 顺序 | 来源 | 管什么 |
|---|---|---|
| 1 | `prototype/*.html` | **最终视觉**。颜色、间距、圆角、字号、动效、布局，全部以这两份文件的实际代码为准 |
| 2 | `03-design-tokens.md` | 设计变量表。原型里的 CSS 变量以此为准，改 token 先改这里 |
| 3 | `04-配色方案.md` | 配色。含每条颜色为什么是这个值、什么颜色被禁用了 |
| 4 | `05-组件清单.md` | 组件规格。某个组件该长什么样、有哪些状态 |
| 5 | `06-动效清单.md` | 动效。每个交互该动多久、动哪个属性 |
| 6 | `02-页面线框.md` | 页面结构 ASCII 图。想知道某页分区怎么切看这里 |
| 7 | `01-信息架构.md` | 信息架构。栏目有哪些、页面之间怎么走 |
| 8 | `00-交付总览.md` | 全部设计决定的索引，外加每个决定的理由 |

**`prototype/` 里的 HTML 是最终答案。** 文档与原型不一致时，以原型为准——
文档是解释，原型是事实。

## 二、两份原型分别是什么

### `prototype/index.html` — 官网首页（landing）

深色。给第一次来的人看"这是个什么东西"。

- 开场动画：三个词在页面正中央原位替换（`更沉浸` → `更恐怖` → `更方便`），
  只在首次访问时播放，可跳过，`sessionStorage` 记忆
- 定位句 + 产品界面截图
- 两个大按钮：一个给创作者、一个给开发者
- 页底 GitHub 按钮

### `prototype/console.html` — 控制台（console）

浅色。给已经知道这是什么、要上手用的人。

六个栏目：

| 栏目 | 原型里的状态 | 说明 |
|---|---|---|
| 引导 | 完整 | 两条路径分叉：有硬件 / 没硬件 |
| ARG 库 | 完整 | 作品列表 |
| 设备 | 完整 | 连接、测试、心跳折线、能力列表 |
| 模拟器 | 完整 | 不接硬件也能看到四路效果 |
| 文档 | **仅 UI 站位** | 三栏：左树 / 中内容 / 右目录。内容是占位文字，待填 |
| 调试 | **仅 UI 站位** | 占位文字，待填 |

外加两个常驻部件：

- **右侧常驻状态栏**：四路通道各自一个图标 + 电平轨道 + 状态词。
  前三路（灯光 / 声音 / 振动）是连续量，用轨道；
  第四路（继电器）是开关量，用 ON/OFF 灯块。**形态即语义，这是刻意的。**
  不设标题——通道名已经能自解释。
- **顶部连接徽标**：当前沿用哪种传输、连没连上。

## 三、怎么用这两份原型

原型是**单文件静态 HTML**，没有构建步骤，双击就能开：

```
双击 design/prototype/index.html
双击 design/prototype/console.html
```

或者在本目录起个静态服务器（推荐，和真实环境更接近）：

```bash
npx serve .          # 或 python -m http.server 8000
# 然后访问 http://localhost:8000/prototype/index.html
```

**原型是可交互的**，但不是功能实现——按钮点了会切页、会有动效，
但背后没有真实数据。它的作用是让你对着抄：

- 抄颜色：直接取 CSS 变量值
- 抄间距：量两个元素之间的距离
- 抄动效：看 `transition` 的时长与缓动
- 抄布局：看 flex/grid 怎么切的

---

## 四、原型不管什么

原型**只管界面长什么样**。它不定义：

- 界面该有哪些功能 → 由 `protocol/`、`firmware/`、`device/`、`sdk/` 决定
- 数据从哪来 → 由 `console/src/core/session.ts` 等底层决定
- 协议怎么发 → 由 `protocol/PROTOCOL.md` 决定

**一句话：原型（连同本目录）定"长什么样"，底层代码定"能干什么"。**

界面上该出现的每一项能力，都要能在底层代码里找到出处——
能找到才做，找不到先问，不要自己发明。

## 五、这个目录从哪来

这套设计是在 ARGX 项目阶段三完成之后、独立做出来的界面方案。
它推翻了阶段二、阶段三实现时用的旧界面（那两套"小白工作台 / 专业工作台"）。

推翻的具体内容、以及为什么推翻，见 `docs/ARGX-04-界面重做.md` 第 1 节。

---

**最后一句：改界面前先打开原型看一眼。** 不要凭记忆写样式。
