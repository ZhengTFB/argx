>
> **v2.0 主要变化**
> 1. 首页改为**标准 Hero 结构**（左文案 / 右代码卡），不再用错落三词当主视觉
> 2. 四拍改为**首访开场动画层**（独立 fixed 层，可跳过，不占页面结构）
> 3. 新增 Hero **规格条**（三项真实参数，解决「空荡荡」）
> 4. 控制台右侧从「彩色进度条」重构为**四路状态指示器**（图标 + 名称 + 电平轨道 + 状态词）
>
> **v2.2 主要变化（阶段六）**
> 1. **开场动画由三词改为四拍** —— 去掉「更恐怖」（`design/` 里已明确「不带入恐怖氛围」，它是仅存的恐怖残留），
>    第 4 拍是 **ARGX 字标**，与前三个词同一位置、同一字号。总时长按同一公式重算：**5450ms**
> 2. **Hero 大标题换成「把你的房间变成密室」**
> 3. **能力三卡改为价值三卡** —— 更沉浸（玩家）/ 更方便（创作者）/ 更易扩展（硬件作者）
> 4. **新增仓库区**（三张等大卡片 + 导航项）
>
> **v2.1 主要变化（质感返工）**
> 1. **删除 Hero 小标签**（`eyebrow` 胶囊 + 脉冲点）—— 过强的「AI 味」符号
> 2. **删除粒子系统**（Canvas 点云 + 全部 JS）—— 效果廉价，改用**单点冷调光锥 + 噪点**做质感
> 3. **删除全部蓝紫渐变** —— 强调色改中性白 + 发丝下划线，整体走向 DeepSeek 式克制冷调
> 4. **开场动画改为「正中央原位替换」** —— 四拍共用同一块画布，逐拍淡出淡入，不再竖排堆叠
> 5. **开场期间隐藏层内除四拍与跳过按钮外的一切**（网格 / 光晕 / 基线 / 进度条），并同步隐藏 `page-shell` 与背景层
> 6. **修复首访判定 Bug** —— 判定与揭屏改为**首帧同步执行**，不再依赖异步回调
> 7. 控制台右栏**删除竖排「输出状态」标题** —— 四路通道名已自解释，栏位更宽松

## 1.2 开场动画层（首访 · 独立层 · 可跳过）

**定位**：`position:fixed; inset:0; z-index:900` 的整屏覆盖层，**不属于页面滚动结构**。
**触发**：`sessionStorage['argx.intro.seen'] !== '1'` 且未开启「减弱动效」时播放。
**核心原则**：四拍**永远在页面正中央原位替换**，不位移、不堆叠；开场期间层内**除四拍与跳过按钮外一律不显示**。

```
┌───────────────────────────────────────────────────────────────────────┐
│                                                                       │
│                                                                       │
│                                                                       │
│                                                                       │
│                                                                       │
│                     更 沉 浸                                          │  ← 四拍共用同一块
│                     ────────                                          │     居中画布（.intro-stage）
│                                                                       │     逐拍原位淡出/淡入
│                                                                       │     当前词底部一道中性高光
│                                                                       │
│                                                                       │
│                                                                       │
│                                                                       │
│                                                                       │
│                        跳过  [ESC]                                    │  ← 唯一的其他元素
└───────────────────────────────────────────────────────────────────────┘
```

**与 v2.0 的差别**：

| 项 | v2.0（已废弃） | v2.1（现行） |
|---|---|---|
| 布局 | `flex-direction:column` 竖排三行堆叠 | `.intro-stage` 单块网格，四拍 `position:absolute` 叠放 |
| 过场 | 上一拍 `on→past`，颜色变灰、上移 4px、缩至 .965（仍在视野内） | 上一拍 `opacity:0` + 缩至 .972，**原地消失**，中心始终只有一拍 |
| 入场位移 | `translateY(26px) scale(.97)` + `blur(10px)` | `translateY(14px) scale(.985)`，**去掉 blur**（廉价感来源） |
| 字动画 | `translateY(.34em) rotateX(24deg)` | `translateY(.3em)` + `blur(6px)→0`，**去掉 3D 旋转** |
| 层内装饰 | 网格 / 光晕 / 基线 / 进度条 全部常显 | **全部隐藏**（`:not(.lit)` 强制 `opacity:0`），仅四拍 + 跳过 |
| 层外内容 | `page-shell{opacity:0}` | `page-shell{visibility:hidden}` + 背景层同步隐藏 |
| 进度条 | 120×2px，与时间线对齐 | **已删除**（属装饰，与「只留四拍」冲突） |

## 1.3 开场动画时间轴（v2.1 原位替换版）

```
t=0ms       ─────────────────────────────────────────
            层已就位（背景纯 --bg-app），页面主体与背景层 visibility:hidden
            层内除四拍与跳过按钮外，无任何装饰元素

t=420ms     「更沉浸」整词入场（opacity 0→1 / translateY 14px→0 / scale .985→1，780ms）
            同时：字内逐字错峰 —— 更(0ms) 沉(105ms) 浸(210ms)
            每字：opacity 0→1 + translateY .3em→0 + blur 6→0（700ms）

t=660ms     当前词底部一道中性白光扫过（scaleX 0→1，900ms，收尾 opacity .42）

t=1470ms    「更方便」在原地淡入；「更沉浸」class on→past
            → opacity 0 + scale .972，原地淡出（不位移，画面中心始终只有一个词）

t=2520ms    「更易扩展」在原地淡入；「更方便」→ past

t=3570ms    「ARGX」字标在原地淡入；「更易扩展」→ past
            字标与前三拍同一位置、同一字号，不是 logo 图

t=4350ms    第四拍完全落位

t=5450ms    自动结束（TOTAL = 420 + 3×1050 + 780 + 1100）
            层 opacity 700ms 淡出 → 680ms 后 remove()
            同时：body 加 .ready（揭屏）→ startReveal()
            首屏 .reveal 元素以 90ms 错峰依次揭示

跳过方式：① 跳过按钮  ② ESC  ③ 点击层任意处
以上任一方式立即结束，并写入 sessionStorage（本次会话不再播放）
```

**关键约束**：动画只动 `opacity / transform / filter`；`prefers-reduced-motion` 时整层 `display:none`，直接进入页面。

## 1.4 背景质感方案（v2.1 重做 · 已删除粒子）

**为什么删粒子**：Canvas 点云在深色底上很难做到「高级」，实际观感偏廉价、且与「专业工具」的调性不符。
**替代方案**：放弃动画元素，改做**静态材质叠加** —— 高级感来自「光的层次 + 微噪点 + 收敛」，而非运动。

```
.z-index 0，position:fixed，inset:0，pointer-events:none
┌──────────────────────────────────────────────────────────────┐
│ ① .bg-light    顶部中央一束冷调柔光（无彩色）                │
│    两层 radial-gradient 叠加：#E4E8EE 11.5% + #EEF1F5 7.5%   │
│    唯一一处「光」，模拟顶灯打在白墙上                        │
│    ::after → 光锥底部一条 760px 水平切线，给光一个落点        │
├──────────────────────────────────────────────────────────────┤
│ ② .bg-vignette 四角径向暗角 52% + 上下线性收敛 46%/50%        │
│    把注意力锁在中心                                          │
├──────────────────────────────────────────────────────────────┤
│ ③ .bg-grid     88px 细网格，白色 2.4%                        │
│    径向 mask 收敛到中心 6% → 76%（越靠边越不可见）            │
├──────────────────────────────────────────────────────────────┤
│ ④ .bg-noise    SVG feTurbulence fractalNoise 4 阶，4.5% 叠加 │
│    唯一的「材质层」，把大平面从死板纯色里救出来              │
└──────────────────────────────────────────────────────────────┘
```

| 要点 | v2.0（已废弃） | v2.1（现行） |
|---|---|---|
| 光 | 3 层**彩色**径向渐变（蓝 #2563EB / 紫 #8B5CF6 / 青 #06B6D4）+ 26s 呼吸 | 1 层**中性冷调**柔光，静态 |
| 运动 | Canvas 粒子 1100 颗 + 鼠标斥力 + 深度雾 | **无** —— 全部静态 |
| 网格 | 64px / 2.2% | 88px / 2.4% |
| 噪点 | 2.8% overlay | 4.5% 普通叠加（更明显，承担材质职责） |
| 暗角 | 仅上下渐变 | 四角径向 + 上下，收敛更强 |
| JS 开销 | rAF 常驻 + 每帧 sort + 逐点径向渐变 | **0** |
| 无障碍 | reduced-motion 下 `display:none` | 无动效，天然合规 |

## 2.2 右侧状态指示器（v2 重写 · v2.1 去标题）

> **设计目标**（用户原话）：「以最简单的方式告诉用户现在各个东西处在什么状态，不需要显示具体参数，一看到得知道这是在显示什么东西」
>
> **v1 的失败**：四个色块大小/形状/位置都不同但毫无规律，静止态只剩 `scaleY(.09)`，看起来就是几个随机色块；加上没有标题、没有名字，完全不知道在表达什么。
>
> **v2 的解法**：每个槽位固定为「图标 → 名称 → 电平轨道 → 状态词」四段式，用**形态差异**而非颜色差异区分通道。
>
> **v2.1 的收尾**（用户原话）：「这栏还是不好，最顶上的输出状态删了就行，也不会太挤了」
> → 删除 `.sb-head` 内竖排的 `.sb-title「输出状态」`（`writing-mode:vertical-rl`，占 56px 高）。栏头仅保留 22px 连接徽标，`.sb-head` 的下间距从 `--space-1` 放宽到 `--space-2`，四个槽位 `flex:1` 自然均分多出的空间。
> → 理由：四路通道名（灯光/声音/振动/继电器）已经自解释，标题属于冗余，且竖排在 76px 窄栏里是纯粹的视觉噪声。

```
单通道槽位（灯光 / 声音 / 振动 —— 连续量）：

     ┌────────┐
     │   💡   │  ← 26px 图标容器（浅色底 + 语义色 + 1px 内描边）
     └────────┘
       灯光      ← 10px 中文名，常显（解决「这是什么」）
     ┌──┐
     │  │       ← 轨道 11px 宽，内凹阴影 + 白色刻度线（形态像仪表，不像色块）
     │▓▓│          · 底部有「零点」参考线，即使待机也能看出量程
     │▓▓│          · 填充 = 线性渐变 c2→c1 + 外发光，过渡 height（量化图示）
     │▓▓│
     │▓▓│
     └──┘
      待机       ← 状态词胶囊：待机 / 渐亮中 / 发声 / 振动

  触发时：图标 scale 1.06 + 外圈 3px 光晕 / 名称转主色 / 状态词转语义色底
```

```
继电器槽位（开关量 —— 形态必须不同）：

     ┌────────┐
     │   ⚡   │
     └────────┘
      继电器      ← 名称同样常显
     ┌────┐
     │ ON │       ← 18px 宽两态灯块，上下刻 ON / OFF 字样
     │ ●  │          · 明确是「开关」而不是「进度条」
     │    │          · 接通：整块转绿渐变，灯点移到上方并加白色辉光
     │ OFF│          · 断开：灰底 + 灰灯点在下
     └────┘
      断开       ← 状态词：断开 / 通路（两态，无渐变）
```

**行为**：
- hover 槽位 → 浅灰底 + 右侧浮出 tooltip（`灯光 · light.main · 亮度/渐变/时长`）
- 与模拟器 / 设备页 / 调试页 **共用同一状态源**：任一页触发，右栏同步变化
- 连接状态徽标：已连接时右上角有 6px 呼吸绿点（2.6s 循环）
