> 本阶段仅设计结构与导航，不含实现。

## 2. 官网首页结构

### 2.1 页面分区（自上而下，靠滚动推进）

| # | 区块 | 高度 | 内容 | 动效 |
|---|---|---|---|---|
| ① | **开场动效** | 100vh | 三个词依次出现：`更沉浸` → `更恐怖` → `更方便`（唯一占屏） | 逐词揭示，最后常驻 |
| ② | **定位区** | auto | 一句话定位 + **产品界面主视觉**（真实界面截图/模拟，非抽象插画） | 滚动进入视口淡入上浮 |
| ③ | **双入口** | auto | 两个**大按钮**（非弹窗）：`我是开发者 → 文档` / `我是玩家 → 控制台` | 卡片式 hover |
| ④ | **页脚** | auto | 一个按钮 `在 GitHub 上浏览` | hover 抬升 |

### 2.2 顶部导航（首页）

```
┌──────────────────────────────────────────────────────────────┐
│  ◇ ARGX          [产品] [文档] [ARG库]        [进入控制台 →]  │
└──────────────────────────────────────────────────────────────┘
   ↑ logo           ↑ 首页为深色透明玻璃，滚动后变实底
```
- 结构对标参考图：左 logo、中导航、右主 CTA 胶囊按钮
- 首页初始为**透明**，滚动超过 Hero 后**吸附顶部 + 加毛玻璃底 + 1px 底边**
- `进入控制台` 为 `--accent-400` 填充胶囊（深色主题）

### 2.3 首页 → 控制台的入口关系

```
              ┌─────────────────────┐
   "我是开发者" ──→  /console/docs       （直达文档，跳过引导）
              └─────────────────────┘
              ┌─────────────────────┐
    "我是玩家"  ──→  /console/onboarding （进入引导，先连通设备）
              └─────────────────────┘
```

## 3. 控制台导航结构

### 3.1 一级导航形态（对标参考图）

控制台采用**两段式侧栏 + 顶部 tab** 的混合结构，与你现有 UI 一致：

```
┌────────┬──────────────────────────────────────────────────────┐
│        │  [引导] [ARG库] [设备] [模拟器] [文档] [调试]        │  ← 顶部胶囊 tab
│ 竖排   ├──────────────────────────────────────────────────────┤
│ 图标   │                                                       │
│ 侧栏   │                    主内容区                            │
│        │                                                       │
│ (56px) │                                                       │
└────────┴──────────────────────────────────────────────────────┘
```

### 3.2 侧栏两态

| 态 | 宽度 | 内容 | 触发 |
|---|---|---|---|
| **收缩态**（默认） | `56px` | 仅图标，hover 出 tooltip | 默认 / 主内容区窄屏 |
| **展开态** | `220px` | 图标 + 文字标签 | 二级页面自动展开 / 手动切换 |

```
收缩态                展开态
┌────┐               ┌──────────┐
│ ⬤  │ 当前项        │ ⬤ 设备   │
│ ⬢  │               │ ⬢ ARG库  │
│ ⬢  │               │ ⬢ 模拟器 │
│ ⬢  │               │ ⬢ 文档   │
│    │               │ ⬢ 调试   │
│ ⬢  │ 底部          │          │
│ ⬢  │               │ ⬢ 帮助   │
└────┘               └──────────┘
```
- 当前项：`--accent-600` 实心圆角方块 + 白色图标（收缩态）／浅蓝底 + 蓝色图标+文字（展开态）
- 侧栏底部固定：帮助 / 用户头像块（参考图右下角）

### 3.3 二级导航（页面内 tab）

参考图详情页的做法：**一级用侧栏，二级用顶部胶囊 tab**。

| 一级页 | 二级 tab |
|---|---|
| 引导 | `快速开始` ｜ `开发者路径` |
| ARG 库 | `全部` ｜ `已安装` ｜ `收藏` |
| 设备 | `连接` ｜ `设备测试` ｜ `设备状态` ｜ `心跳记录` ｜ `能力列表` |
| 模拟器 | `四路面板` ｜ `时序回放` |
| 文档 | 侧栏树形导航（不用 tab） |
| 调试 | `指令台` ｜ `参数` ｜ `输出流` |

```
控制台 / ⌂ > 设备 > 心跳记录
              └───┘  └──────┘
              一级      二级

- 每段可点击回退；末段为当前页，不可点

## 5. 三类用户的路径分流

### 5.1 用户角色 → 目标 → 入口

| 角色 | 核心诉求 | 首选入口 | 首次落地页 |
|---|---|---|---|
| **内容创作者** | 选剧本、触发效果，不想懂技术 | 首页「我是玩家」 | `/console/onboarding`（新手路径） |
| **开发者** | 接 SDK、看协议、调参数 | 首页「我是开发者」 | `/console/docs`（直达文档） |
| **玩家/观众** | 只体验效果 | 不访问控制台，或经作品分享链接 | 作品运行页 |

### 5.2 引导页的两条独立路径（关键设计点）

**这是两个不同目标的引导，不是一套流程的两种措辞。**

```
                    ┌──────────────────────────┐
                    │      引导入口页           │
                    │   "你想做什么？"          │
                    └────────┬─────────────────┘
                             │
          ┌──────────────────┴──────────────────┐
          ▼                                      ▼
┌─────────────────────────┐        ┌─────────────────────────┐
│  路径 A：新手连通路径      │        │  路径 B：开发者路径       │
│  （面向内容创作者）        │        │  （面向开发者）           │
├─────────────────────────┤        ├─────────────────────────┤
│ 目标：连上设备 → 开始游玩  │        │ 目标：接入 SDK / 深入调试 │
│                         │        │                         │
│ ① 插上开发板（图示引导）   │        │ ① 选择接入方式           │
│ ② 自动扫描设备（一键）     │        │    · 复制 SDK 片段        │
│ ③ 连接成功反馈（灯闪一下） │        │    · 查看协议文档         │
│ ④ 试一下（点一个按钮，    │        │ ② 进入调试台             │
│    设备真的动起来）        │        │ ③ 打开示例工程           │
│ ⑤ → 进入 ARG 库 选作品    │        │                         │
│                         │        │ 出口 → /console/docs     │
│ 出口 → /console/library │        │ 或 /console/debug       │
└─────────────────────────┘        └─────────────────────────┘
```

**设计约束**
- 路径 A：**每一步只做一件事**，全程 ≤ 5 步，每步有明确的"成功反馈"
- 路径 B：**允许信息密度高**，直接给代码、协议、命令，不做过场动效
- 两条路径**可随时切换**（引导页顶部有两个 tab），但**不共用进度条**

### 5.3 全站用户动线总览

```

        ┌────────┴────────┐

   [我是开发者]       [我是玩家]

## 6. 右侧常驻响应预览条（用户创新点）

### 6.1 定位
**全局常驻组件**，横跨控制台所有页面，固定在主内容区最右侧。

### 6.2 设计意图
不写任何文字标签，用**纯视觉**让用户随时看到"什么在被响应"。

```
┌─────┐
│     │  灯光    ──── 橙色竖条（高度/亮度随信号变化）
│  ▓  │
│     │
├─────┤
│     │  声音    ──── 蓝色竖条（高度随强度变化）
│  ▓  │
│     │
├─────┤
│     │  振动    ──── 紫色竖条（高度随强度变化）
│  ▓  │
│     │
├─────┤
│     │  继电器  ──── 绿色块（只有亮/灭两态，不做渐变）
│  ▓  │
└─────┘
  ↑ 56px 宽，无文字，纯色条
```

### 6.3 关键规则

| 规则 | 说明 |
|---|---|
| **无文字** | 不标"灯光/声音/振动/继电器"，用颜色区分（颜色已在别处建立认知） |
| **顶部小状态点** | 仅在最上方放一个连接状态点（绿=已连接，灰=未连接），是整条唯一的文字外元素 |
| **不占主内容宽度** | 固定在视口右侧，主内容区右内边距为其预留 `72px`，不重叠 |
| **响应频率** | 信号变化用 `transform: scaleY()`，**只动 transform** |
| **静止态** | 无信号时显示为极淡的轨道（`--bg-muted`），不消失（保留位置感） |
| **窄屏降级** | `< 1024px` 收起为 40px；`< 640px` 隐藏，改为顶部一行迷你条 |

### 6.4 四路的视觉差异化（延续"前三路 vs 第四路"的区别）

| 通道 | 形态 | 说明 |
|---|---|---|
| 灯光 | 竖条 + **渐变时长可视化**（条内有一道移动的亮块表示渐变进度） | 连续量 + 时长 |
| 声音 | 竖条 + **脉冲波纹**（发出时条边缘泛光） | 连续量 + 时长 |
| 振动 | 竖条 + **高频抖动**（快速小幅 scaleY 抖动） | 连续量 + 时长 |
| 继电器 | **方块翻转**（两态，中间过渡极快） | 纯开关量 |

> 这一条是整份设计里"信息自解释"的核心：用户不需要读文字，看形态就知道哪路是连续的、哪路是开关的。

## 7. 导航决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 导航形态 | 顶部胶囊 tab + 左侧图标栏 | 与你现有 UI 一致，二级信息用 tab 分区 |
| 侧栏默认态 | 收缩（56px） | 主内容区优先，避免长期占用 220px |
| 面包屑 | 仅二级+页面显示 | 一级页面标题即导航，加面包屑是冗余 |
| 首页双入口 | 大按钮，不用弹窗 | 用户明确要求；弹窗会打断"浏览→决策"的节奏 |
| 文档/调试 | 给结构不给内容 | 本阶段范围限定 |
