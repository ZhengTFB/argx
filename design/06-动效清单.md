# ARGX 动效清单

> 版本 **v2.1** ｜ 电脑端（桌面），hover 为主要触发方式
> **硬约束**：只动 `transform` / `opacity` / `filter` / 颜色 / `box-shadow` / `clip-path`。禁止 `width` `height` `top` `left` `margin`。
> 全站默认支持 `prefers-reduced-motion`。
>
> **v2.1 变更**：① 开场动画改为**正中央原位替换**（删除 `blur(10px)` 入场与 `rotateX` 字动画）；② **删除背景粒子**与**光带呼吸**两项常驻动效（背景改为纯静态）；③ 删除开场进度条动效；④ 删除 Hero `eyebrow` 脉冲点动效；⑤ 新增「首帧同步揭屏」机制说明。

## 二、首页动效

### 2.1 开场动画层三词揭示 ★ 核心动效（v2.1 原位替换版）

```
触发：首访（sessionStorage 未标记）且未开减弱动效
前置：判定在「首帧内同步完成」—— 不播放则立即 startReveal() + body.ready，页面不会闪
时间轴：
  t=0      层就位（纯 --bg-app）；层内除三词与跳过按钮外，装饰一律 opacity:0
           同时 body.intro-open：page-shell 与背景层 visibility:hidden
  t=420    「更沉浸」整词入场  opacity 0→1 / translateY(14px→0) / scale(.985→1)  780ms
           字内错峰：更(0) 沉(105ms) 浸(210ms)
           每字：opacity 0→1 / translateY(.3em→0) / blur(6px→0)  700ms
  t=660    底部高光扫过  scaleX 0→1  900ms  终点 opacity .42（中性白，非彩色）
  t=1470   「更恐怖」原地淡入；「更沉浸」→ .past（opacity:0 + scale .972，原地消失）
  t=2520   「更方便」原地淡入；「更恐怖」→ .past
  t=3300   第三词完全落位
  t=4400   自动结束：层 opacity 700ms 淡出 → 680ms 后 remove()
           → 移除 intro-open → 加 body.ready（揭屏）→ startReveal()
```

| 属性 | 值 |
|---|---|
| 动效属性 | `opacity` + `transform`(translateY/scale) + `filter: blur` + `color` |
| 整词时长 | 780ms |
| 单字时长 | 700ms，错峰 105ms |
| 缓动 | `cubic-bezier(.22,1,.36,1)` |
| 中心约束 | 三词全部 `position:absolute; left:50%; top:50%`，`transform` 基准 `translate(-50%,-50%)` —— **永远在正中央，不位移不堆叠** |
| 跳过 | 按钮 / `ESC` / 点击层任意处 → 立即 `finish()`，写 sessionStorage |
| reduced-motion | 整层 `display:none !important`，首帧同步 `startReveal()` |

**v2.0 → v2.1 删减**：入场位移 `26px → 14px`；删除整词 `blur(10px)`（廉价感主要来源）；字动画删除 `rotateX(24deg)`，改为 `blur(6px)→0`；`.past` 从「变灰 + 上移 4px + 留在视野」改为「**opacity:0 原地消失**」。

### 2.2 首帧同步揭屏（v2.1 新增 · 修复首访判定 Bug）

| 属性 | 值 |
|---|---|
| 问题 | v2.0 下非首访时所有元素不显示 —— 判定分支未移除 `intro-open`，且 `startReveal()` 未被调用，`.reveal` 元素停在 `opacity:0` |
| 根因 | 依赖异步回调（`setTimeout` / `transitionend`）决定揭屏时机，任一环节异常即永久不可见 |
| 解法 | 判定改为**首帧同步执行**：不播放 → 同步 `el.remove()` + `startReveal()` + `body.ready`；播放 → 同步 `body.intro-open` |
| 保底 | 末尾追加 `requestAnimationFrame(forceVisible)`：强制移除 `intro-open`、加 `ready`、给所有 `.reveal` 加 `.on` |
| 可见性开关 | `.page-shell{visibility:hidden}` + `body.ready .page-shell{visibility:visible}`（`visibility` 不参与过渡，无闪烁） |
| reduced-motion | `body.intro-open .page-shell{visibility:visible !important}` 双重兜底 |

### 2.3 背景氛围层（v2.1 · 已改为纯静态，无动效）

|---|---|
| v2.0（已废弃） | Canvas 粒子 rAF 常驻 + 3 层彩色光带 26s 呼吸 |

## 三、控制台通用动效

### 3.0 右侧状态指示器动效 ★（v2 新增）

| 元素 | 触发 | 属性 | 时长 |
|---|---|---|---|
| `.sb-ico` | 通道激活 | `scale(1→1.06)` + `box-shadow` 加 3px 外光晕 | 140ms |
| `.sb-name` | 通道激活 | `color` → `--text-primary` | 140ms |
| `.sb-fill` | 数值变化 | `height` 4% → 目标值（**图示量化，非布局动画**） | 260ms `--ease-out` |
| `.sb-state` | 状态切换 | 底色 + 文字色 → 语义色 | 140ms |
| `.sb-conn::after` | 已连接 | `opacity 1→.35→1` 呼吸 | 2600ms 循环 |
| `.sb-binary` | 继电器切换 | 底色整块硬切（`0ms`）+ 灯点 `margin-bottom` 位移 | 90ms `linear` |
| `.sb-tip` | hover 槽位 | `opacity 0→1` + `translateX(4px→0)` | 140ms |
| `.sb-heart svg` | 常驻 | `heartBeat`：`opacity .5→1` + `scale(1→1.14)` | 2000ms 循环 |

**关键设计点**：继电器用 `0ms` 硬切，与前三路的 `260ms` 渐变形成**动效层面的连续量／开关量区分**——这是「形态即语义」在时间维度上的延伸。

**reduced-motion**：`.sb-heart` 呼吸与 `.sb-conn` 呼吸停止；其余位移保留（属状态反馈，不是装饰）。

### 3.1 页面/视图切换 ★

```
切换一级页（点顶部 tab）：
  旧内容：opacity 1→0 + translateY(0→-8px)    180ms
  新内容：opacity 0→1 + translateY(8px→0)     300ms（延迟 180ms 开始）
  总时长：480ms
  缓动：--ease-reveal

切换二级 tab（页内）：
  内容区：opacity 0→1 + translateX(8px→0)     260ms
  指示器：translateX + 宽度用 clip-path 模拟，260ms
```

> **用交叉淡入，不做滑动推挤**。侧栏和顶部 tab 保持静止，只有内容区变化。

## 六、模拟器与实时可视化动效 ★ 核心

### 6.1 四路可视化差异（动效层面的形态区分）

| 通道 | 动效形态 | 技术实现 | 时长/周期 |
|---|---|---|---|
| **灯光** | 平滑爬升 + 平滑回落（像呼吸灯） | 渐变环的 `stroke-dashoffset` 连续变化（`clip-path` 亦可）；色块 `opacity` 跟随亮度 | 跟随渐变时长参数 |
| **声音** | 脉冲式：快速起振 → 衰减 | 波形 `scaleY` 从中心向外爆发，然后回落 | 起振 80ms，衰减 300ms |
| **振动** | 高频抖动：持续的小幅震颤 | `scaleY` 以随机幅度抖动 | 周期 60ms，持续参数时长 |
| **继电器** | 硬切：0 → 1 瞬时 | `scaleY` 直接切到目标值，`transition: none` | 0ms |

> **这四种形态差异是"信息自解释"的关键**：用户看形态就知道哪路是连续量、哪路是开关量，不需要读文字。

### 6.2 触发时的连锁反馈

```
点击 [ 触发 ] 按钮：
  t=0      按钮：背景 → active 色，回弹 0ms（不缩放）
  t=0      该通道卡片：边框亮起通道色     140ms
  t=40     卡内可视化：开始播对应动效
  t=40     右侧预览条对应色条：同步动效（两条必须严格同帧，用同一个时间源）
  t=40     KPI/状态数字（若有）：开始变化
  t=结束   全部回到静息态，卡片边框淡出   260ms
```

**关键**：主区卡片和右侧预览条**必须同步**，它们读的是同一个信号源。

### 6.3 实时可视化的性能约束

- 所有实时动效**必须用 `transform` 和 `opacity`**，绝不用 `height`
- 高频更新（振动）用 `will-change: transform` 提升合成层
- 同时运行的实时动效**不超过 4 个**（四路各一），超出队列化
- 页面不可见时（`document.hidden`）**暂停所有实时动效**

## 十二、全局 reduced-motion 实现

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
    scroll-behavior: auto !important;
  }

  /* v2.1：开场动画层整层移除，直接进入页面（首帧同步，不会闪） */
  #intro { display: none !important; }
  .intro-word { opacity: 1 !important; transform: translate(-50%,-50%) !important; }
  .intro-word .ch { opacity: 1 !important; transform: none !important; filter: none !important; }

  /* v2.1：背景层已纯静态，只需保证开场态不锁住可见性 */
  body.intro-open { overflow: auto !important; }
  body.intro-open .page-shell { visibility: visible !important; }
  body.intro-open .bg { visibility: visible !important; }

  /* 实时可视化降级为静态示意 */
  .channel-viz { animation: none !important; }

  /* 视差与微光关闭 */
  .visual-parallax, .skeleton-shimmer, .ph-line::after { display: none !important; }

  /* 状态点不再呼吸 */
  .status-pill .dot, .sb-conn::after, .sb-heart svg, .step.act .sdot::after {
    animation: none !important;
    opacity: 1 !important;
  }

**另需 JS 层检查**：
- 若 JS 中有 `requestAnimationFrame` 驱动的实时动效（视差、振动模拟），必须用 `matchMedia('(prefers-reduced-motion: reduce)').matches` 判断并直接跳过，不能只靠 CSS 兜底。
- **开场动画的判定必须在首帧同步完成**（`reduce || sessionStorage`）；不播放分支必须同步调用 `startReveal()` 并加 `body.ready`，否则页面元素会永久停在 `opacity:0`。
- 末尾追加 `requestAnimationFrame(forceVisible)` 作为保底：强制移除 `intro-open`、加 `ready`、给所有 `.reveal` 加 `.on`。
