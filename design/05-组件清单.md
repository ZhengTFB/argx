## 二、核心组件规格

### 2.0 v2 新增组件规格

#### IntroLayer（开场动画层）

> v2.1 重做：三词改为**正中央原位替换**，层内**除三词与跳过按钮外一律不显示**。

| 属性 | 值 |
|---|---|
| 定位 | `position:fixed; inset:0; z-index:900`；`hidden` 属性由首帧脚本控制 |
| 背景 | `var(--bg-app)` 纯色（**不再有中心光晕**） |
| 画布 | `.intro-stage`：`display:grid; place-items:center`；`width:100%`；`height:1.06em`；`font-size:clamp(54px,9.2vw,108px)` |
| 三词 | 全部 `position:absolute; left:50%; top:50%`，`transform` 基准 = `translate(-50%,-50%)` —— **永远在正中央，不位移不堆叠** |
| 字号 / 字重 | `font-size:inherit`（继承 stage）／`weight:800`／`letter-spacing:-.045em` |
| 入场 | `opacity 0→1` + `translateY(14px)→0` + `scale(.985)→1`（780ms `--ease-reveal`） |
| 逐字 | `.ch`：`opacity 0→1` + `translateY(.3em)→0` + `blur(6px)→0`（700ms）；`transitionDelay = ci × 105ms` |
| 状态类 | `.on`（当前，白色 + `scale(1)`）｜ `.past`（已过，`opacity:0` + `scale(.972)` + `#585D65` —— **原地消失**） |
| 收尾 | 当前词底部 `::after` **中性白**高光 `scaleX 0→1`（900ms，终点 opacity .42） |
| 装饰隔离 | `#intro:not(.lit) .intro-grid, #intro:not(.lit)::before, #intro:not(.lit)::after { opacity:0 !important; animation:none !important }` |
| 跳过 | 按钮（含 `ESC` kbd）｜`ESC` 键｜点击层任意处（层本身 `cursor:pointer`） |
| 记忆 | `sessionStorage['argx.intro.seen'] = '1'` |
| 无障碍 | `role="dialog"` `aria-label` `aria-modal="true"`；`aria-live="polite"` 在 stage 上；`prefers-reduced-motion` → `display:none !important` |
| 时序 | 首词 420ms／词间 1050ms／词内 105ms／末词后停留 1100ms／总时长 4400ms |
| **首帧同步** | 判定 `reduce \|\| sessionStorage` 后**同步**决定「不播放 → 立即 `startReveal()` + `body.ready`」或「播放 → `body.intro-open`」，**不依赖任何异步回调** |

#### AmbientBackground（首页氛围层 · v2.1 取代 ParticleField）

> v2.1 **删除**粒子系统（Canvas 点云 + 深度雾 + 鼠标斥力）与三层彩色光带，改为**纯静态四层叠加**。

| 层 | 元素 | 规格 |
|---|---|---|
| ① 光 | `.bg-light` | `left:50%; top:-38%; width:150%; height:108%`；两层中性冷调 radial-gradient（`rgba(228,232,238,.115)` + `rgba(238,241,245,.075)`）；`::after` 为 760px 水平切线 |
| ② 收敛 | `.bg-vignette` | 四角径向 `rgba(0,0,0,.52)` @100% + 上 `.46` / 下 `.50` 线性收敛 |
| ③ 网格 | `.bg-grid` | 88px；白色 `.024`；mask 椭圆 `82%×58% at 50% 28%`，`6% → 76%` |
| ④ 噪点 | `.bg-noise` | SVG `feTurbulence fractalNoise baseFrequency=.78 numOctaves=4 stitchTiles=stitch`；`opacity:.045` |
| 容器 | `.bg` | `position:fixed; inset:0; z-index:0; pointer-events:none`；底色 `#0A0B0D` |
| 动画 | — | **无**。零 rAF、零 JS，天然满足 `prefers-reduced-motion` |
| 隔离 | `body.intro-open .bg{visibility:hidden}` | 开场期间背景层不参与绘制 |

#### StateSlot / LevelTrack / BinaryLamp（右侧状态指示器）

**容器 `SidebarStatus`**：`sticky; top:0; height:100vh; width:76px; flex-direction:column`

| 子组件 | 规格 |
|---|---|
| `.sb-head` | **仅** 连接徽标 22px（已连接时右上角 6px 呼吸绿点）；v2.1 **删除**竖排标题「输出状态」 |

| `.sb-ico` | 26px 圆角方块；浅色底 + 语义色 + 1px 内描边；激活时 `scale(1.06)` + 3px 外光晕 |
| `.sb-name` | 10px / 600 / `--text-secondary`；**常显**（解决「这是什么」） |

### 5. ChannelCard（四路通道卡）★ 关键组件

**这是本设计最重要的业务组件。前三路与第四路是同组件不同变体。**

```
通用结构：
┌─────────────────────────────────────────┐
│ [●] 灯光            light.main          │  ← 通道点 + 中文名 + 代号(mono, 次要)
│ ──────────────────────────────────────  │
│                                         │
│  ┌───────────────────────────────────┐  │
│  │        实时可视化区                │  │  ← 各变体形态不同（见下）
│  └───────────────────────────────────┘  │
│                                         │
│  亮度  ────────●──────  70%             │  ← 参数行（无滑杆的变体没有）
│  渐变  ──────●────────  800ms           │
│  ──────────────────────────────────────  │
│                        [ 触发 ]         │
└─────────────────────────────────────────┘
```

| 变体 | 可视化形态 | 参数控件 | 底部 |
|---|---|---|---|
| `light.main` | **渐变环**（环形进度，表示渐变过程） | 3 个滑杆：亮度/渐变/持续 | [触发] |
| `sound.beeper` | **声波脉冲**（横向波形条） | 2 个滑杆：强度/时长 | [触发] |
| `motion.vibrate` | **高频抖动条**（密集颗粒） | 2 个滑杆：强度/时长 | [触发] |
| `env.relay` | **两态开关块**（硬切，无过渡） | **无滑杆**，1 个 Switch | [触发] |

**视觉差异的强制要求**：`env.relay` 变体**禁止出现滑杆**，`Switch` 组件的轨道切换**无缓动**（`transition: none`），因为是物理量。

```
  hover    背景 --bg-surface-hover，图标 --text-primary；90ms
  active   背景 --accent-600（收缩）/ --accent-50（展开），
           图标 #FFF（收缩）/ --accent-600（展开）
  focus    --shadow-focus 外环
```

**展开/收起动画**：宽度变化用 `clip-path` + `transform` 组合模拟（**不动 width**），文字用 opacity 淡入，260ms。

底部固定区：帮助图标 + 用户头像块（头像 28px 圆 + 名字 + 角色 + chevron）。

### 10. EmptyState

### 14. ChannelBar（预览条的单个色条）★ 创新组件

```
容器宽度：56px（整条），单通道高：flex 1 平均分
色条宽度：20px，居中
色条圆角：--radius-sm (6px) 上下（像一条柱子）
色条背景：对应通道色

形态差异（关键）：
  灯光    scaleY 平滑跟随（transform-origin: center）
  声音    脉冲波纹（scale 短暂放大 + opacity 泛光）
  振动    scaleY 高频抖动（60ms 周期小幅）
  继电器  scaleY 0 / 1 硬切，中间无过渡

静止态：色条高度 6px，背景 --bg-muted（保留位置感，不消失）
变化：只动 transform，不碰 height
```

## 四、组件状态覆盖清单（交付验收用）

每个交互组件**必须**覆盖以下状态，缺一不可：

| 状态 | 说明 | 验收 |
|---|---|---|
| default | 静息态 | ✅ |
| hover | 鼠标悬停 | ✅ |
| focus-visible | **键盘**聚焦（不是鼠标点击的 focus） | ✅ 必须有可见环 |
| active/pressed | 激活（桌面端仅变色/位移，不缩放） | ✅ |
| disabled | 禁用 | ✅ |
| loading | 加载中（仅 Button/表格/列表） | ✅ |
| error | 错误（仅表单组件） | ✅ |

> **focus-visible 是硬性要求**：全站任何可点击元素都必须有键盘 focus 环，使用 `--shadow-focus`。
