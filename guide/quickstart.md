## 1 · 插上装置

用一根 USB **数据线**把开发板接到电脑。纯充电线里没有数据针脚：板子会亮，但电脑看不到它。

> [!WARNING]
> ESP32-S3-DevKitC-1 板上有两个 USB-C 口。控制台认标着 USB 的那一个，即原生 USB 口。另一个标着 UART 或 COM，只供电，插它设备页会一直连不上。

## 2 · 在控制台里连上它

打开控制台的「设备」栏目，点「连真实装置（USB 串口）」。弹出的端口选择框由**操作系统**绘制，网页读不到里面的内容，所以控制台里没有设备列表。选中带 USB 字样的端口。

没有硬件时点「连虚拟装置」。虚拟装置与真机跑**同一套会话层**，界面表现一致，区别是效果不会发生在你的房间里。

## 3 · 验证它真的通了

在设备页点「运行全测」。四路依次亮一遍，每一路都要等装置把状态**回查回来**才判定通过。哪一路没接线，哪一路就是黄叹号。

> [!NOTE]
> 绿勾的判断依据是 `ARGX.state()` 的应答。装置拔了线，本地记得发过指令也不会亮绿勾。

```text
// [head]
设备页 → 连接 → 连真实装置 → 选端口
设备页 → 连接测试 → 运行全测
四路都绿 → 去 ARG 库挑一个作品
```
