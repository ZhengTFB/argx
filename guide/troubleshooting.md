## 点连接，浏览器不弹端口选择框

- 用的是 Chrome / Edge 桌面版吗？Firefox 和 Safari 不支持 Web Serial
- 地址栏是 localhost 还是 https？file:// 下串口被禁用
- 重复点了：第一次弹框后浏览器会记住授权，第二次可能直接连上而不弹框
- 按钮是不是在某个被 await 打断的调用栈里？中间插了等待，浏览器就认为这次点击已经过期了

## 连上了，但灯不亮

- 先看右侧状态栏：触发时它有没有动？**动了**说明指令走通了，问题在接线那一头（去看 firmware/WIRING.md）
- **没动**说明帧根本没被处理：去调试页看时间线，`→` 那一行有没有发出去、`←` 那一行有没有 ack
- 有 ack 但 r 是 dropped：优先级不够，被更强的一条压住了
- 灯亮却看不出变化：检查限流电阻。LED 必须串 220~330Ω，不串会烧
- 继电器不吸合：模块 VCC 必须接 5V / VIN，从 3V3 取电带不动

## 装了固件，装置没反应

- 没用原生 USB 口。S3 板子上要插标着 USB 的那个口
- Arduino IDE 里 USB CDC On Boot 没开成 Enabled：板子在跑，但串口是哑的
- 用的是老款 ESP32-WROOM-32E：它没有原生 USB，Web Serial 实际上连不上。这一版只保证它能编译通过
- 板子一直在重启：多半是振动马达直连了 GPIO。马达必须经三极管或驱动模块，直连会烧引脚或触发欠压复位

## 界面显示"信号弱"或掉线

- 确认数据线插紧了，换一根线试试（劣质线是常见原因）
- 会话层每 3 秒发一次 ping；6 秒没应答标成 stale，10 秒判掉线。短暂 stale 是正常的，掉线才需要处理
- 在调试页看心跳记录表：延迟那一列一直偏大，说明链路本身不稳

## 模拟器正常，真机不对

两者走的是同一套会话层，所以差异一定出在**装置那一侧**：引脚接错、元件没接、供电不够。虚拟装置没有电气部分，不会暴露"电阻忘了串"这类问题。

## 调试页的四个功能

- 收发时间线：每一帧收发都在这里，可以只看错误
- 手动发 cue：绕开你的作品，直接发一条看装置回什么
- 故障注入：把装置弄坏（不发 ready / 丢包 / 垃圾串扰 / 半路断连），看界面撑不撑得住
- input 注入：验证反向通道（装置 → 网页）
