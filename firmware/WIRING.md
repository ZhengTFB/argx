# ARGX 接线说明

写给**不懂硬件的人**。照着这一页接，不需要看别的文档。

引脚号在 `firmware/argx_mvp/capabilities.h` 里定义，改接线只改那一处。
本页的引脚表与那份定义必须一致。

---

## 0. 先搞清楚：板子上的两个 USB 口

ESP32-S3-DevKitC-1 上有**两个** USB-C 口，插错了现象完全不同：

| 口 | 丝印 | 说明 | 要做的设置 |
|---|---|---|---|
| 原生 USB | `USB` | Web Serial 首选。数据传输走芯片自己的 USB | Arduino IDE 里把 **USB CDC On Boot 设为 Enabled**，否则串口是哑的 |
| 串口芯片 | `UART` | 板载 CP2102 转出来的串口 | 不用改设置，但**必须用 115200 波特率** |

- 刷固件用哪个口都行；**跑 Web Serial 建议用 `USB` 口**（延迟低、不需要驱动）
- 两个口都插上不会更快，只会让你分不清哪个是哪个。**只插一个。**
- 老款 ESP32-WROOM-32E 板子只有一个 Micro-USB 口，走的是串口芯片，同 `UART` 那一行

## 1. 引脚总表

| 能力 | 引脚 | 接什么 | 电平类型 |
|---|---|---|---|
| `light.main` | **GPIO4** | LED（必须串电阻）/ LED 灯带信号线 | PWM |
| `sound.beeper` | **GPIO18** | 有源或无源蜂鸣器 | PWM 2.7kHz |
| `motion.vibrate` | **GPIO17** | 振动马达（**必须经三极管**） | PWM |
| `env.relay` | **GPIO16** | 继电器模块信号脚 | 数字，高电平吸合 |
| 公共 | **GND** | 所有外设的地 | — |

**为什么是这四个脚**：在 S3 和经典 ESP32 上都安全。
避开了会影响启动的 strapping 脚（GPIO0/2/5/12/15）、
经典 ESP32 上接内部 flash 的 GPIO6~11、只进不出的 GPIO34~39、
以及 S3 的 N8R8 用来接 PSRAM 的 GPIO33~37。

## 2. 逐项接线

### 2.1 灯 `light.main`（GPIO4）

```
GPIO4 ──[ 220Ω~330Ω 电阻 ]──[ LED 长脚(正) ]
GND   ─────────────────────[ LED 短脚(负) ]
```

- **电阻必须有**。3.3V 直接怼 LED，轻则烧灯，重则烧 GPIO。
- 电阻值 220Ω 偏亮，330Ω 偏暗但更安全。手边有什么用什么，**别不接**。
- 灯带（WS2812 之类）：数据线接 GPIO4，**灯带的 VCC 和 GND 必须单独供电**，
  ESP32 的 3V3 带不动一条灯带。灯带 GND 与 ESP32 GND 要接通。

### 2.2 蜂鸣器 `sound.beeper`（GPIO18）

```
GPIO18 ──[ 蜂鸣器 ]── GND        （有源蜂鸣器，两根线，直接接）
GPIO18 ──[ 100Ω ]──[ 无源蜂鸣器 ]── GND   （无源蜂鸣器，三极管驱动更响）
```

- 两根线，不用分极性也能响（不响就把两根对调）
- 固件用的是 2.7kHz 方波：**有源蜂鸣器**照样响，**无源蜂鸣器**在这个频率最响
- 音量调不了，只做开关（有 / 无）

### 2.3 振动马达 `motion.vibrate`（GPIO17）

```
GPIO17 ──[ 1kΩ ]──[ NPN 三极管基极 ]
GND ──[ 马达 ]──[ 三极管集电极 ]
三极管发射极 ── GND
马达两端反过来并一只二极管（1N4007；正极接 GND 那侧）
```

- **马达绝对不能直接接 GPIO**：启动电流几百毫安，GPIO 只能出 ~12mA，
  直接接的结果是板子不断重启，或者引脚永久损坏。
- 那只二极管是续流用的：马达断电瞬间会反冲出高压，没有它三极管会先死。
- 不想焊三极管：直接买**马达驱动模块**（一行 VCC/GND/IN），IN 接 GPIO17。

### 2.4 继电器 `env.relay`（GPIO16）

```
继电器模块 VCC ── 板子 5V/VIN（不是 3V3！）
继电器模块 GND ── 板子 GND
继电器模块 IN  ── GPIO16
```

- **VCC 必须接 5V/VIN**。3.3V 驱动不动线圈，会出现"咔咔响但吸不上"或板子重启
- 多数模块是**低电平触发**的。如果你的模块吸合逻辑反了，
  把 `capabilities.cpp` 里 `handleRelay()` 的 `HIGH`/`LOW` 对调即可
- 继电器控制的**市电设备（如台灯）**：不熟悉强电就别接。
  继电器次级侧是 220V，接线端子和低压侧必须分开走线。

## 3. 独立供电（这条最容易出事）

| 外设 | 能不能从 ESP32 取电 |
|---|---|
| 单颗 LED（串了电阻） | 可以，从 3V3 取 |
| 蜂鸣器 | 可以，从 3V3 取 |
| 振动马达 | **不能**。必须单独供电（或至少经三极管从 5V 取） |
| LED 灯带 | **不能**。一米 60 灯全亮接近 4A |
| 继电器模块 | **不能**。线圈从 5V/VIN 取，不要再从 3V3 拉 |

**单独供电时，外部电源的 GND 必须和 ESP32 的 GND 接在一起**（共地）。
没共地的话信号是悬空的，表现是"时好时坏"或完全没反应。

## 4. 常见接线错误对照表

| 现象 | 大概率原因 |
|---|---|
| 板子插上电脑没任何反应，也不出串口 | 用了 `UART` 口但没装 CP2102 驱动；或线是**只能充电的 USB 线** |
| 串口连上了，但一条协议帧都收不到 | `USB CDC On Boot` 没设 Enabled（用原生 USB 口时） |
| 一接外设板子就反复重启 | 外设从 3V3 取了太多电；或马达/继电器直连 GPIO |
| 灯完全不亮 | LED 极性接反；或 GPIO4 与 GND 之间量不到电压（先把电阻和灯串一起检查） |
| 灯常亮，控制不了 | 接在了 3V3 上而不是 GPIO4 上 |
| 蜂鸣器一直响 | `i` 收到的是 0 但模块是低电平触发的，逻辑反了 |
| 一插上就下载不了程序 | 外设接在 strapping 脚上（GPIO0/2/5/12/15）把电平拉住了；拔掉外设再刷 |
| 接在 GPIO6~11 上（老款 WROOM-32E） | 这些脚接了内部 flash，**通电即启动失败** |
| 时好时坏 | 没有共地 |
| Chrome 里点连接没反应 | 页面不是 `https://` 或 `localhost`（Web Serial 硬性要求） |
| 手机上连不上 | 手机浏览器不支持 Web Serial，**只能桌面 Chrome/Edge** |

## 5. 只接一个灯的最简验证

不想一次接四个，就先只接 GPIO4 的 LED：

1. 按 2.1 接好 LED（记得串电阻）
2. 用 `USB` 口把板子插到电脑
3. 浏览器打开控制台页面（阶段二产物），点连接
4. 触发一次 `light.main` 的 cue，灯应该亮起；不再发帧后 15 秒内自动熄灭

**灯在 15 秒后自己灭掉是正常的**，那是看门狗在兜底
（协议规定：15 秒收不到任何有效帧，自动回 idle，防止玩家关掉浏览器后灯一直亮着）。
